# What models do you use?

Codebuff uses different models for different tasks. The orchestrator coordinates; subagents handle specific jobs.

## Orchestrator

The main agent ("Buffy") coordinates everything:

<MarkdownTable>
  | Mode | Model |
  |------|-------|
  | Default | Opus 4.8 |
  | Plan | Opus 4.8 |
  | Max | Opus 4.8 |
  | Free | MiniMax M2.5 |
</MarkdownTable>

## Subagents

The orchestrator spawns these for specific jobs:

<MarkdownTable>
  | Task | Models |
  |------|--------|
  | Code editing | Claude Opus 4.8, GLM 4.7 |
  | Thinking/reasoning | Claude Opus 4.8, GPT-5.2 |
  | Code review | Claude Opus 4.8, GPT-5.2 |
  | File discovery | Gemini 2.5 Flash Lite, Grok 4.3 |
  | Terminal commands | Claude Haiku 4.5, Grok 4.3 |
  | Web/docs research | Grok 4.3 |
</MarkdownTable>

Max mode runs multiple implementations in parallel and picks the best one. Default mode runs a single implementation pass. Free mode uses MiniMax M2.5 and includes code review support.

File rewrites use speculative decoding from Relace AI.
